# Kutuphane (Library Management System) -- Console Project

A simple library management system built with Visual Studio and utilises SQL database. This project manages books, users, and the transactions in the library database.

## ✨ Features
- Add, Delete, Edit and Update book informations
- Add, Delete, Edit and Update user informations
- Add, Delete, Edit and Update book transactions
- SQL-based backend for data storage

## 🛠 Technologies Used

- C#
- SQL Server Integration
- CRUD Operations
- Object Oriented Programming (OOP)
- Combination of connected and disconnected architecture
- Simple Console UI

## 🚀 Setup
1. Clone the repository
2. Open `Kutuphane.sln` in Visual Studio
3. Build the solution and run the project

## 🚀 Database Setup
1. Use `create-tables.sql` to create the necessary database tables in SQL Server.
